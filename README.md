# Heart Disease Prediction Using Machine Learning

## 📌 Project Overview
This project focuses on building a Machine Learning classification model using Python to predict the likelihood of heart disease based on clinical patient attributes. It aims to assist healthcare providers in early detection and risk assessment.

## 📊 Dataset
The dataset utilized in this project includes clinical features of patients such as:
- Age & Sex
- Chest Pain Type (CP)
- Resting Blood Pressure (trestbps)
- Cholesterol Levels (chol)
- Maximum Heart Rate Achieved (thalach)

## 🛠️ Tools & Libraries Used
- **Platform:** Kaggle & GitHub
- **Language:** Python
- **Libraries:** Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn

## 🚀 Key Steps Performed
1. **Data Exploration (EDA):** Analyzed correlations and visualized data distributions.
2. **Data Preprocessing:** Handled missing values, encoded categorical variables, and scaled numerical features.
3. **Model Training:** Implemented Machine Learning classification algorithms to find the best-performing model.
